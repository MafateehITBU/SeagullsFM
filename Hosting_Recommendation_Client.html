Hosting Recommendation

VPS for CMS, three radio websites (Mood, Watar, Beat), and mobile apps

1. Project overview

  • Backend: One MERN API (Node/Express + MongoDB) used by the CMS, three websites, and mobile apps.
  • Web: Three dynamic sites (Mood, Watar, Beat) with forms and functionality, plus one CMS (admin panel).
  • Streaming: Live FM via Zetta third-party service (we use their endpoints; no streaming server on our side).
  • Database: MongoDB (recommended: MongoDB Atlas so the VPS focuses on app and web only).
