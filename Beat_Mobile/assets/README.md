# Assets Folder

This folder contains the app's static assets (images, icons, etc.).

## Required Assets

Based on `app.json`, you need to add the following files:

1. **icon.png** - App icon (1024x1024px recommended)
   - Used as the main app icon for iOS and Android

2. **splash.png** - Splash screen image
   - Recommended size: 1242x2436px (or similar aspect ratio)
   - Will be displayed on app launch

3. **adaptive-icon.png** - Android adaptive icon foreground (1024x1024px)
   - Used for Android adaptive icons

4. **favicon.png** - Web favicon (48x48px or larger)
   - Used when running the app on web

## Asset Guidelines

- Use PNG format for best compatibility
- Ensure icons have transparent backgrounds where appropriate
- Follow platform-specific guidelines for icons
- Optimize images for mobile to reduce app size

## Temporary Placeholders

You can use placeholder images during development. Replace them with final assets before production builds.
