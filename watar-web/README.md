# Watar FM Web

Public website for Watar FM — React + Vite + Tailwind CSS (same stack as `beat-web`).

## Setup

```bash
cd watar-web
npm install
npm run dev
```

## Env

Copy / edit `.env`:

- `VITE_API_BASE_URL` — backend API base (local: `http://localhost:5001/api`)
- `VITE_STATICINFO_CHANNEL` — CMS channel name (`WatarFM`)
